# Security Policy

## Supported Versions

PyASL Studio has not published a versioned release yet. Security fixes are
applied to the latest code on the `main` branch only.

| Version                | Supported          |
| ---------------------- | ------------------ |
| `main` (latest commit) | :white_check_mark: |
| Older commits / forks  | :x:                |

This table will be updated once versioned releases are published.

## What to Include in a Report

To help us investigate quickly, please include:

- A description of the vulnerability and its potential impact
- Steps to reproduce the issue
- Expected behavior and actual behavior
- The affected version or commit hash
- Any relevant logs, screenshots, or a proof of concept

Please do not include real patient data or other sensitive personal
information in your report.

## Response and Disclosure Process

- We will acknowledge your report as soon as possible.
- We will investigate, confirm the issue, and keep you informed of progress.
- Vulnerability details will be kept private until the issue has been
  investigated and a fix is available.
- Once a fix is released, we may publish an advisory and, with your
  permission, credit you for the report.

Thank you for helping keep PyASL Studio and its users safe.
